## 一、问题发现与修复过程

### 问题1: MCP Router 数据库连接失败

**现象**:
```
[MCP-Router] 从数据库加载Cookie失败: connect ECONNREFUSED ::1:8080
```

**根本原因**:
- MCP Router 尝试连接 `http://localhost:8080` 加载 Cookie
- 但在 Zeabur 容器中，后端服务不在本地 8080 端口
- 环境变量 `CLAUDE_AGENT_URL` 未设置，使用了错误的默认值

**修复方案**:
```typescript
// processManager.ts 第 170-174 行
const backendUrl = process.env.CLAUDE_AGENT_URL
  || process.env.BACKEND_URL
  || 'https://xiaohongshu-automation-ai.zeabur.app'; // 使用生产域名作为默认值
```

**修复结果**: ✅ 成功从数据库加载 12 个 Cookie

### 问题2: REST API 参数映射错误

**现象**:
```
Key: 'UserProfileRequest.UserID' Error:Field validation for 'UserID' failed on the 'required' tag
Key: 'UserProfileRequest.XsecToken' Error:Field validation for 'XsecToken' failed on the 'required' tag
```

**根本原因**:
xiaohongshu-mcp 的所有工具都需要 `xsec_token` 参数，但我们的 REST API 端点没有传递：

| 工具 | 需要的参数 | 我们之前传的 |
|-----|-----------|-------------|
| user-profile | `user_id`, `xsec_token` | 无 |
| feed-detail | `feed_id`, `xsec_token` | 只有 `feed_id` |
| search | `keyword`, `filters` | `keyword`, `sort` |
| like | `feed_id`, `xsec_token` | 只有 `feed_id` |
| favorite | `feed_id`, `xsec_token` | 只有 `feed_id` |
| comment | `feed_id`, `xsec_token`, `content` | 缺少 `xsec_token` |

**修复方案**:
更新所有 REST API 端点，添加必需的 `xsecToken` 参数：
```typescript
// 示例: feed-detail 端点
app.post('/agent/xiaohongshu/feed-detail', async (req: Request, res: Response) => {
  const { userId, feedId, xsecToken } = req.body;

  if (!xsecToken) {
    return res.status(400).json({ success: false, error: 'xsecToken is required' });
  }

  const result = await mcpAuthClient.callMCPTool(userId, 'xiaohongshu_get_feed_detail', {
    feed_id: feedId,
    xsec_token: xsecToken  // 添加必需参数
  });

  res.json({ success: true, data: result });
});
```

**修复结果**: ✅ feed-detail 成功返回笔记详情

### 问题3: GET 请求参数传递错误

**现象**:
```
GET /api/v1/feeds/search  400
error: '缺少关键词参数'
code: 'MISSING_KEYWORD'
```

**根本原因**:
MCP Router 的 `callTool` 方法对 GET 请求使用了 `data` 传参，但 axios 对 GET 请求应该用 `params`：

```typescript
// 错误的代码
const response = await axios({
  method: 'GET',
  url: 'http://localhost:18060/api/v1/feeds/search',
  data: { keyword: '美食', filters: { sort: 'general' } }  // ❌ GET 请求不应该用 data
});
```

**修复方案**:
```typescript
// processManager.ts
const axiosConfig: any = {
  method,
  url,
  headers: { 'Content-Type': 'application/json' },
  timeout,
};

if (method.toUpperCase() === 'GET') {
  axiosConfig.params = data; // ✅ GET: 参数作为 query string
} else {
  axiosConfig.data = data;   // ✅ POST: 参数作为 request body
}

const response = await axios(axiosConfig);
```

**修复结果**: ✅ search 成功返回搜索结果

4. **Cookie 有效期**: Cookie 会过期，需要定期重新登录
