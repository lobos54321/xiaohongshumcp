# 快速开始 - Claude Code Agent 测试 MCP 工具

## 第一步：获取你的 User ID

### 方法 1: 从浏览器开发者工具获取

1. 访问生产环境: `https://xiaohongshu-automation-ai.zeabur.app`
2. 打开浏览器开发者工具 (F12)
3. 切换到 **Console** 标签
4. 输入以下代码并回车:

```javascript
// 获取 localStorage 中的映射数据
const mappings = JSON.parse(localStorage.getItem('xhs_user_mappings') || '{}');
console.log('User ID:', Object.values(mappings)[0]);
```

5. 复制显示的 User ID (格式类似: `xhs_user_abc123...`)

### 方法 2: 从浏览器 Network 请求中获取

1. 访问生产环境并登录
2. 打开开发者工具 (F12) → **Network** 标签
3. 刷新页面
4. 搜索 `check-login-status` 请求
5. 查看 Request Payload 中的 `user_id` 字段

### 方法 3: 直接从代码中查找

如果你有 Supabase 访问权限:

```sql
SELECT xhs_user_id FROM xiaohongshu_user_mappings
WHERE supabase_uuid = 'YOUR_SUPABASE_UUID';
```

## 第二步：配置测试文件

编辑配置文件:

```bash
cd /Users/boliu/xiaohongshumcp-current
nano claudedocs/agent-test-config.json
```

修改 `user_id`:

```json
{
  "user_id": "xhs_user_abc123..."  // 👈 粘贴你的 User ID
}
```

保存并退出 (Ctrl+X, Y, Enter)

## 第三步：确保已登录小红书

1. 访问: `https://xiaohongshu-automation-ai.zeabur.app`
2. 如果显示登录页面，扫码登录
3. 确保进入了 "运营仪表盘" 页面

## 第四步：运行测试

```bash
cd /Users/boliu/xiaohongshumcp-current
node claudedocs/run-mcp-test.js
```

## 常见错误处理

### ❌ 错误: "用户未登录或 Cookie 已过期"

**原因**: Cookie 过期或未登录

**解决方法**:
1. 重新访问 `https://xiaohongshu-automation-ai.zeabur.app`
2. 扫码登录
3. 重新运行测试

### ❌ 错误: "请在配置文件中填写正确的 user_id"

**原因**: 配置文件中的 `user_id` 未修改

**解决方法**:
按照第一步获取正确的 User ID 并填入配置文件

### ❌ 错误: "无法获取 feed_id，跳过后续测试"

**原因**: 账号首页动态为空，且搜索结果也为空

**解决方法**:
1. 登录小红书官网/App，关注一些用户
2. 修改配置文件中的 `search_keyword`，使用更常见的关键词 (如 "美食"、"旅行")

### ⚠️ 测试超时

**解决方法**:
编辑配置文件，增加超时时间:

```json
{
  "test_settings": {
    "timeout_seconds": 60  // 从 30 增加到 60 秒
  }
}
```

### ⚠️ 频繁限流

**解决方法**:
编辑配置文件，增加测试间隔:

```json
{
  "test_settings": {
    "delay_between_tests_ms": 5000  // 从 3000 增加到 5000 毫秒
  }
}
```
