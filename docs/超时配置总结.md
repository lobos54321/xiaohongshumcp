## 超时配置合理性分析

### ✅ 配置合理的部分

1. **前端 45秒 < MCP Router 120秒**
   - 给MCP Router足够的缓冲时间
   - 前端不会过早超时

2. **Element查找 30秒 < 前端 45秒**
   - 快速失败原则
   - 配合三层降级机制（MCP Go → Playwright → Auto Detection）

3. **MCP Router 120秒 > 前端 45秒**
   - 链路逐层增加超时时间
   - 避免底层超时但顶层还在等待

### ⚠️ 需要注意的部分

1. **WaitForLogin 240秒 > MCP Router 120秒**
   - **不是问题**：WaitForLogin在异步goroutine中执行
   - 二维码返回后，goroutine继续在后台等待扫码
   - 用户扫码成功后，goroutine会保存Cookie
