# MCP Router 日志查看器使用指南

## 🎯 功能概述

为了解决"发布卡在 50%"的问题，我们添加了完整的日志缓存和查看功能，现在可以直接在浏览器中实时查看所有 MCP 进程的日志，无需访问 Zeabur 控制台。

## 📊 新增功能

### 1. 日志缓存系统

- **自动捕获**: 每个 MCP 进程的 stdout 和 stderr 自动缓存
- **时间戳**: 每条日志都带有精确的时间戳
- **内存保护**: 每个进程最多保存 500 条最近的日志
- **实时更新**: 日志实时写入缓存，无延迟

### 2. HTTP API 端点

#### 查看所有用户日志
```bash
GET /api/logs?limit=100

# 响应示例
{
  "success": true,
  "timestamp": "2025-01-15T10:30:00.000Z",
  "logs": [
    {
      "userId": "user_xxx",

        "[2025-01-15T10:29:56.000Z] [MCP user_xxx] [MCP Auth] Publishing content"
      ]

  "totalUsers": 1
}
```

#### 查看指定用户日志

### 3. Web 日志查看器

访问 URL: **`https://your-zeabur-domain.com/logs.html`**

#### 功能特性

1. **实时查看**:
   - 自动刷新（可选，每 5 秒）
   - 手动刷新按钮

2. **多种过滤**:
   - 按用户 ID 过滤
   - 关键词搜索（高亮显示）
   - 数量限制（50/100/200/500 条）

3. **智能高亮**:
   - 错误日志：红色显示
   - 成功日志：绿色显示
   - Cookie 日志：黄色显示
   - 搜索关键词：蓝色高亮

4. **美观界面**:
   - VS Code 深色主题
   - 响应式布局
   - 流畅滚动

## 🔍 如何诊断发布问题

### 步骤 1: 访问日志查看器

打开浏览器访问: `https://your-zeabur-domain.com/logs.html`

### 步骤 2: 输入用户 ID

在"用户ID"输入框中输入你的用户 ID：
```
user_9dee489189a644ee_prome
```

### 步骤 3: 点击"刷新日志"

系统会自动加载该用户的最近 100 条日志。

### 步骤 4: 查看关键日志

#### ✅ 正常发布流程应该看到：

```
🍪 [Cookie加载] 当前工作目录: /app/data/cookies/user_xxx
🍪 [Cookie加载] Cookie文件路径: cookies.json
🍪 [Cookie加载] ✅ 成功加载Cookie，大小: XXXX 字节
[MCP Auth] Publishing content
开始查找上传输入框
开始上传图片
成功上传图片
开始填写标题
开始填写正文
准备查找发布按钮
成功发布内容
```

#### ❌ 问题诊断表

| 日志状态 | 问题位置 | 可能原因 |
|---------|---------|---------|
| 没有 `🍪 [Cookie加载]` | 代码未部署 | 需要等待 Zeabur 重新部署 |
| 有 Cookie 日志，但加载失败 | Cookie 文件问题 | Cookie 文件损坏或不存在 |
| 只有 `[MCP Auth] Publishing` | 导航失败 | Cookie 无效或小红书页面变化 |
| 卡在 `开始查找上传输入框` | 页面元素查找 | 选择器失效 |
| 卡在 `开始上传图片` | 图片上传 | 图片路径错误或格式问题 |
| 卡在 `开始填写标题` | 标题填写 | 页面元素变化 |

### 步骤 5: 使用关键词搜索

在"过滤"输入框中输入关键词，例如：
- `Cookie` - 查看 Cookie 相关日志
- `ERROR` - 查看错误日志
- `成功` - 查看成功操作
- `开始` - 查看流程步骤

### 步骤 6: 启用自动刷新

勾选"自动刷新"选项，系统会每 5 秒自动刷新日志，便于实时监控发布进度。

## 🔧 技术细节

### 日志缓存实现

```typescript
interface ManagedProcess {
  process: ChildProcess;
  port: number;
  userId: string;
  lastUsed: number;
  cleanupTimer?: NodeJS.Timeout;
  logs: string[];        // 保存最近的日志
  maxLogs: number;       // 最多保存 500 条
}

// 日志捕获
childProcess.stdout?.on('data', (data: Buffer) => {
  const message = `[MCP ${userId}] ${data.toString()}`;
  console.log(message);
  saveLog(message);  // 保存到缓存
});
```

### API 端点实现

```typescript
// 获取所有用户日志
app.get('/api/logs', (req, res) => {
  const limit = req.query.limit ? parseInt(req.query.limit as string) : 100;
  const allLogs = processManager.getAllLogs(limit);
  res.json({ success: true, logs: allLogs });
});

// 获取指定用户日志
app.get('/api/logs/:userId', (req, res) => {
  const { userId } = req.params;
  const limit = req.query.limit ? parseInt(req.query.limit as string) : 200;
  const logs = processManager.getLogs(userId, limit);
  res.json({ success: true, userId, logs });
});
```
